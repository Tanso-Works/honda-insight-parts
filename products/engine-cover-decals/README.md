# Engine Cover Decals — ZE1 Honda Insight

Overlay decals for the IMA engine cover on the Honda Insight (ZE1 generation).

## Variants

| Variant | Description |
|---|---|
| **Power of Dreams** | Classic Honda tagline — raised lettering |
| **OE IMA** | Factory IMA badging style |
| **Parody IMA** | Playful take on the IMA logo |

## Print Settings

| Parameter | Recommendation |
|---|---|
| Material | TPU 95A (or higher) |
| Layer height | 0.12mm (or 0.08mm for finer text) |
| Supports | None needed |
| Orientation | Lettering facing up |
| Bed temp | 45-60°C (PEI) |
| Nozzle | 0.4mm |
| Post-processing | Scissors / snips to remove small brim if any |

## Installation

1. Clean the IMA cover surface thoroughly with isopropyl alcohol
2. Dry-fit the decal to confirm alignment
3. Peel backing and press firmly from center outward
4. Heat gun (low) can help conform to curves
