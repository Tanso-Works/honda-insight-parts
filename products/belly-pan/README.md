# ZE1 Belly Pan — Honda Insight Under-Body Aero Panel

Under-body aluminum belly pan / aero undertray for the first-generation (ZE1) Honda Insight (2000–2006). Reduces under-car drag and turbulence, smooths the airflow, and shields the exhaust / drivetrain vitals from road debris.

## Material & Fabrication

| Parameter | Spec |
|---|---|
| Material | 5052-H32 aluminum |
| Thickness | 0.040 in (~1.0 mm) |
| Bends | 2 brake bends (SendCutSend-formed) |
| Blank size | 37.745 × 26.558 in |
| Finish | Raw — Type III anodize / paint optional |

## Files

| File | Description |
|---|---|
| `cad/BellyPan.step` | Source CAD — single manifold solid (520 × 181.5 × 382 mm envelope), ~40 mm clearance radii + 5 mm corner reliefs |

## Notes

- **Iteration 1** — a fit-check / baseline blank. Mounting and bend tolerance should be verified on the vehicle before a production run.
