# HVAC Temp Control Knob — D-Shaft Coupler Repair (ZE1)

Replacement D-shaft coupler for the broken temperature-control knob on the first-generation (ZE1) Honda Insight. Presses into the OEM knob to restore a firm grip on the HVAC temp-control D-shaft.

## Print Settings

| Parameter | Recommendation |
|---|---|
| Material | PETG (PA6-CF for extra rigidity) |
| Layer height | 0.12 mm |
| Infill | 100% — or 6+ perimeters/walls |
| Supports | None |
| Orientation | D-shaft bore vertical |
| Nozzle | 0.4 mm |
| Bed temp | 70–80°C (PETG) |
| Notes | Small torsional part — maximize walls for strength |

| File | Description |

## Installation

1. Remove the broken coupler remnant from the knob (pick out any cracked plastic).
2. Press the printed coupler into the knob until seated.
3. Fit the knob back onto the HVAC temp-control D-shaft and confirm it grips before refitting the dash trim.
